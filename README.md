## What Is Narinig Mo Ba?

**Narinig Mo Ba?** is a story-driven psychological horror game set in a Filipino **sari-sari store**.

You play as the store owner and spend your shift serving customers from the neighborhood.

At first, everything feels ordinary.

Customers ask for products, you search the shelves, check prices, accept payments, and return the correct change.

But something slowly begins to feel wrong.

Everyday gossip starts to carry more meaning. Names and stories begin to connect. Familiar conversations start sounding like warnings, and the seemingly cozy store gradually becomes the center of a much darker story.

Narinig Mo Ba? was originally created for **Game Jam Los Baños 2026**. The post-game-jam release added improvements including an HTML5 browser build and native desktop versions.

## Narinig Mo Ba? Gameplay

![Narinig Mo Ba? gameplay](./narinig%20mo%20ba8.png)

The gameplay combines simple store-management interactions with narrative psychological horror.

### Listen to Customers

Read each customer's full request before selecting a product.

The dialogue is more than background conversation. Names, rumors, debts, relationships, and subtle changes in tone help build the story.

### Find the Requested Product

Search around the sari-sari store for the correct item.

Products can appear on:

- store shelves
- hanging sachets
- refrigerator displays
- counter areas
- other parts of the shop

Some packages look similar, so pay attention to what the customer actually asks for.

### Check the Price

If necessary, check the price of the item before returning to the counter.

Selecting the correct product and remembering its price are part of the store gameplay.

### Count the Change

Customers pay using Philippine pesos.

After accepting payment, select the correct bills and coins to return the customer's change.

### Follow the Story

Don't rush through the conversations.

The ordinary store routine is how Narinig Mo Ba? introduces its characters, neighborhood, and psychological horror mystery.

## How to Play Narinig Mo Ba?

The basic gameplay loop is:

1. Read the customer's complete request.
2. Find the requested product inside the store.
3. Pick up the correct item.
4. Check its price when necessary.
5. Return to the counter.
6. Accept the customer's payment.
7. Give the correct peso change.
8. Listen to the conversation.
9. Continue serving customers as the story develops.

The first requests introduce these mechanics naturally, so there is no need to rush.
